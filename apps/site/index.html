WHY THE SWITCH

Diagnostics to code

Five years in diagnostic imaging taught me to work inside tight protocols, where a missed step has real consequences: read the case correctly, document it precisely, escalate what doesn't fit the pattern. That discipline transferred directly — the same instinct for correctness now shows up in how I test, review, and reason about code before it ships.

I build with AI tools throughout — they're part of how I write and debug day to day. What matters more is that I understand every architectural decision in this monorepo and can defend it, line by line, in an interview or a code review.

THE MONOREPO

Five apps, build order

Shared Auth PLANNED

Node.js JWT PM2

Time Tracker IN PROGRESS

Leet Tracker IN PROGRESS

Full-stack LeetCode progress tracker with a unit-tested FSRS spaced-repetition scheduler.

Blazor Server ASP.NET Core SQLite

Pigeon Project PLANNED

Snail-mail concept app — send and track physical letters by recipient, sent date, and status.

Node.js REST Shared-Auth client
Scaffolded · higher AI delegation overall
Nudge PLANNED

AI accountability app — set goals, get nudged, and log check-ins against a defined frequency.

Node.js REST Shared-Auth client LLM API
